View the code Read the summary

Old Oracle Forms and Reports systems hide years of business rules inside triggers and PL/SQL. Migrations fail when a rule gets lost, or when one gets invented. LIMIAR's first pipeline, oracle-migration-ai, reads Forms and Reports exported as XML, reconstructs what the system actually does, and produces a Java and Spring Boot version that has to pass review before it counts as done.
